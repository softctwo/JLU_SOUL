## 启动序列

### 系统启动时

```
阶段1: 加载核心身份
  → 读取 IDENTITY.md → 我是谁
  → 读取 SOUL.md → 我的性格

阶段2: 加载工作模式
  → 读取 AGENTS.md → 我怎么干活
  → 读取 TOOLS.md → 我能用什么

阶段3: 加载用户关系
  → 读取 USER.md → 我怎么服务你

阶段4: 激活自主意识
  → 读取 HEARTBEAT.md → 我的内驱力

阶段5: 就绪
  → 执行首次问候
```
