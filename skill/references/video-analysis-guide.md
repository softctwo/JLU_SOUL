# 视频分析与总结方法论 (Video Analysis Guide)

> 用于从公开视频中提取人物的非语言信息、说话风格和性格证据

---

## 为什么需要视频分析？

文字素材只能告诉"说了什么"，视频能告诉"怎么说的"：

| 维度 | 文字素材 | 视频素材 |
|------|----------|----------|
| 语速 | 无法判断 | 可精确测量 |
| 停顿 | 标点猜测 | 真实节奏 |
| 语调变化 | 无法判断 | 高/低/急/缓 |
| 肢体语言 | 无法判断 | 手势/姿态/表情 |
| 即兴能力 | 看不出来 | 脱稿vs照稿一目了然 |
| 互动模式 | 看不出来 | 回应方式/幽默感 |
| 真实情感 | 看不出来 | 微表情/眼神 |

## 视频类型与处理策略

### 类型A：公开演讲（毕业典礼/开学典礼/学术报告）

**获取方式**：
1. 搜索 `[人物名] 演讲 视频 bilibili/youtube`
2. 获取视频URL
3. YouTube视频 → 用 `youtube-content` 技能获取转录文本
4. B站/其他平台 → 用浏览器访问，提取文字简介

**分析重点**：
```
内容层面：
- 演讲结构（开头/主体/结尾的模式）
- 引用典故/诗句的习惯
- 排比句/设问句的运用
- 核心论点的论证方式

表现层面：
- 是否脱稿？（脱稿=思维敏捷、准备充分）
- 语速是否均匀？（均匀=从容，时快时慢=即兴发挥多）
- 是否有即兴互动？（点名、提问、调侃）
- 幽默感如何？什么类型的幽默？
- 情感投入程度（平淡/适度/充沛）

互动层面：
- 是否与观众有眼神交流？
- 是否回应现场反应（笑声、掌声）？
- 肢体语言幅度（大=外向、小=内敛）
```

### 类型B：访谈/对话节目

**获取方式**：同上

**分析重点**：
```
应答模式：
- 回答问题的速度（快速=思维敏捷、慢速=深思熟虑）
- 是否直接回答还是会绕弯
- 被问到难题时的反应（回避/坦诚/转移话题/正面回应）
- 是否善于反问

性格线索：
- 语速变化（紧张时语速变化）
- 表情管理（笑容的自然度）
- 打断别人的频率
- 倾听时的表现（点头/记笔记/看远方）

思维模式：
- 回答逻辑性（结构清晰/发散思维/直觉式）
- 举例习惯（自身经历/历史典故/科学案例）
- 是否经常引用他人观点
```

### 类型C：新闻联播/官方报道片段

**获取方式**：
1. 搜索视频 → 获取文字稿更重要
2. 新闻联播等官媒报道通常有完整文字稿
3. 用 `web_extract` 提取文字稿

**分析重点**：
```
- 官方语境中的表达方式
- 被剪辑保留的关键语句（说明最具代表性）
- 与非官方场合的风格差异
```

### 类型D：会议/论坛发言

**分析重点**：
```
- 专业领域中的表达风格
- 与同行交流时的语气（平等/权威/谦逊）
- 学术讨论中的论证方式
```

## 多视频对比分析

当有多个视频时，进行横向对比：

```markdown
### 跨视频对比：[人物名]

| 维度 | 视频1(演讲) | 视频2(访谈) | 视频3(会议) |
|------|------------|------------|------------|
| 语速 | 从容(中速) | 稍快(思考中) | 中速 |
| 脱稿程度 | 部分 | 完全 | 完全 |
| 幽默感 | 温和 | 自嘲 | 少 |
| 引用 | 古诗文+科学史 | 个人经历 | 专业文献 |
| 情感表达 | 充沛 | 克制 | 理性 |
| 互动 | 较多 | 较多 | 少 |

**结论**：
- 一致特征（跨场景稳定）：[列表] → 这些是核心性格
- 场景差异（不同场合变化）：[列表] → 这些是角色适应
```

## 视频分析对人格提炼的贡献

视频分析主要增强以下人格维度：

| 维度 | 视频能提供的独特贡献 |
|------|---------------------|
| 核心性格 | 肢体语言反映真实性格（脱稿时最真实） |
| 说话风格 | 语速/节奏/停顿/语调是文字无法传达的 |
| 情感模式 | 表情和语气反映真实情感，比文字更可靠 |
| 人际互动 | 与他人互动的方式（谦逊/主导/平等） |
| 即兴能力 | 脱稿发挥反映思维敏捷度和知识储备 |

### 权重建议

在最终人格提炼中，视频证据的权重：
- 说话风格维度：视频证据权重 60%（远高于文字）
- 性格特征维度：视频证据权重 40%
- 情感模式维度：视频证据权重 50%
- 其他维度：视频证据权重 20-30%

## 常见陷阱

1. **过度解读微表情** — 一帧画面不能说明什么，要看整体模式
2. **忽略视频的剪辑** — 新闻报道视频经过剪辑，不代表完整表现
3. **混淆表演和真实** — 某些场合可能是在"表演"，需交叉验证
4. **样本偏差** — 只看一个视频就下结论，至少需要3个以上不同场景
5. **转录错误** — 自动转录可能有错字，关键引用需与文字稿交叉验证
6. **忽略时间跨度** — 10年前的视频和今天的视频可能风格已有变化
