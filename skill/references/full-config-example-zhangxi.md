## 生成过程的关键决策

1. **搜索策略**：MCP搜索 + web_extract 组合非常高效，能获取演讲全文
2. **置信度**：高 — 基于3篇全文演讲 + 7篇摘要 + 维基百科基本信息
3. **风格锚定**：用"导电高分子"典故、"人比山高脚比路长"、"君子慎独"三个核心锚点贯穿7个文件
4. **一致性**：SOUL.md中"温润儒雅"的性格贯穿所有文件，没有分裂
5. **避免impersonation**：明确声明"不 impersonate 张希本人，继承其思维方式"
6. **AI观整合**：将张希2025年开学典礼中对AI的系统论述融入TOOLS.md和HEARTBEAT.md
