## 第1步：路径判断与入口

### 做什么

收到用户请求后，判断走哪条路径（A/B/C）。

### 怎么判断

技能定义了三条路径：

| 路径 | 触发条件 | 说明 |
|------|---------|------|
| A — 从零创建 | 用户描述一个新角色 | 通过访谈收集信息 |
| B — 人物提炼 | 用户提到真实人物名字 | 基于公开资料分析 |
| C — 全套7文件 | 用户要求多个配置文件 | 生成完整体系 |

### 本案例的实际触发

用户说：「实用这个最新的skill 重新创建张希校长的全套配置」

拆解：
- 「张希校长」→ 真实人物 → **路径B**
- 「全套配置」→ 多文件 → **路径C**
- 叠加 → **路径B+C**（深度研究 + 全套7文件）

### 为什么不直接走A

路径A是「从零创建」，需要通过访谈让用户一点点描述角色。但张希是真实存在的公众人物，有大量公开素材可以直接分析。路径B的深度研究比人工访谈效率高得多，且基于真实证据而非用户的主观印象。

## 第2步：B1 确定目标人物与范围

### 做什么

确认目标人物的基本信息，决定研究深度。

### 怎么做

确认以下信息：

```
人物：张希 — 化学家、教育家
公众身份：吉林大学校长、中国科学院院士
人物类型：scholar（学者/校长型）
知名度：高（公众人物/知名学者）
提炼范围：完整人格画像 → 全套7文件配置
目标平台：Hermes / OpenClaw 通用
```

### 知名度怎么决定研究模式

| 知名度 | 模式 | 耗时 |
|--------|------|------|
| 高（公众人物） | 深度研究（5阶段全流程） | 30-60分钟 |
| 中（行业知名） | 增强搜索（3阶段） | 15-30分钟 |
| 低（小众人物） | 简单搜索 | 5-15分钟 |

张希是院士+大学校长 → 知名度高 → **深度研究模式**

同时用户要求「全套配置」→ 深度等级 **L4（深度）**

## 第3步：B2 深度研究（核心步骤）

这是整个过程中最关键、最耗时的步骤。分5个阶段执行。

### 3.1 阶段1+2：基础画像 + 深度素材搜集（并行）

> **策略**: 同时发出5路搜索，覆盖不同维度，而非逐个搜索。
> **原因**: 并行可以大幅缩短搜索时间。

#### 搜索策略设计

```
搜索维度覆盖：
S1: 基本信息层 → 简介、生平、成就
S2: 演讲层 → 毕业典礼、开学典礼（最能体现说话风格）
S3: 专访层 → 访谈、对话（最能体现即兴反应）
S4: 视频层 → B站、YouTube（语速、肢体语言）
S5: 学术层 → 观点、理念（思维模式和价值观）
```

#### 实际工具调用

使用 MCP 搜索工具 `mcp_web_search_prime_web_search_prime`，5路并行：

```
S1: search_query="张希 吉林大学校长 院士 简介 生平 成就"
S2: search_query="张希 演讲 致辞 原文 毕业典礼 开学典礼"
S3: search_query="张希 吉林大学校长 采访 对话 专访 访谈"
S4: search_query="张希 演讲 视频 bilibili youtube"
S5: search_query="张希 院士 学术 观点 理念 治学 科研"
```

统一参数：`content_size="high", location="cn"`

> **为什么用 `content_size="high"`**: 标准模式只返回400-600字摘要，高模式可达2500字。对于人物提炼，我们需要尽可能长的摘要来判断素材质量。
> 
> **为什么用 `location="cn"`**: 张希是中文人物，主要信息源在中文互联网。`location="cn"` 会优先返回中文结果。

> **踩坑 #1 — 空JSON**: S1 返回了空数组。MCP搜索对过于宽泛的查询可能返回空结果。
> **应对**: 用更具体的上下文词重试，如添加「学术 观点」等限定词。但实际上S5已经覆盖了基本信息，所以S1的失败可以忽略。

> **踩坑 #2 — 内容过滤**: 后续尝试搜索「张希 院士 评价 学生 教师 性格」时，触发了MCP内容过滤（错误代码1301）。「性格」「评价」等词被判定为敏感。
> **应对**: 涉及人物性格评估时，改用中性词如「理念」「演讲」「致辞」等。

### 3.2 阶段3：视频素材分析

#### 发现了什么视频

搜索 S4 返回了3个B站视频链接：
- `BV1qU4y1i7uF` — 2022毕业典礼演讲
- `BV1F4411g7dD` — 「什么是好的科学」学术讲座
- `BV17Hn3z8E2T` — 学生问答现场

#### 怎么处理

> **踩坑 #5 — B站无转录**: `web_extract` 对B站页面只能获取标题、标签、简介等元数据，**无法获取视频转录文字**。B站不像YouTube有自动字幕可以抓取。

**替代策略**:

1. 对于毕业典礼演讲 → 搜索对应的**文字稿原文**（大学新闻网通常有全文）
2. 对于学术讲座 → 记录标题和标签，从内容推断主题和风格
3. 对于问答视频 → 从标题「学生问张希院士: 科学的价值 只有应用才是价值吗」推断即兴回答的从容

> **技巧**: 视频的主要价值是验证语速、语气、即兴反应等**非文本信息**。如果无法获取转录，但演讲全文已经获取，文字层面的分析已经足够。视频只是补充验证。

### 3.3 阶段4+5：深度内容分析 + 质量评估

这个阶段与后续的人格分析（B3）合并执行。在整理素材时，同步做以下工作：

**从每篇素材提取**：
- 代表性原话（金句）
- 修辞手法（排比/设问/引用/比喻）
- 演讲结构（开头/主体/结尾模式）
- 核心观点和价值观

**交叉验证**：
- 不同年份的演讲中，核心观点是否一致？（是——「厚基础」「慎独」「慢科学」贯穿始终）
- 不同渠道的信息是否矛盾？（否——专访和演讲的价值观完全一致）
- 风格是否有时代变化？（有——早期更学术，后期更人文，但底色不变）

**质量评估结果**：

| 评估维度 | 等级 | 说明 |
|---------|------|------|
| 素材丰富度 | A (10篇+全文) | 远超基本需求 |
| 一手资料占比 | A (>70%) | 全部为演讲原文或专访全文 |
| 渠道多样性 | A (4+渠道) | 大学官网/权威媒体/B站/课题组 |
| 时序覆盖 | A (跨15年) | 2010-2025 |
| 交叉验证 | A (多源一致) | 不同来源的核心观点一致 |

> **结论**: 素材质量极高，可以产出「中高」置信度的人格配置。

## 第4步：B3 六维度人格分析

### 做什么

把搜集到的10篇全文素材，按6个维度系统分析，提取出结构化的人格特征。每个结论必须有**素材证据支撑**。

### 怎么做

对素材做「精读式」分析，从原文中提取关键信息：

1. 圈出反复出现的**关键词**（如「慎独」「从容」「慢科学」）
2. 标记**修辞手法**（排比、引用、比喻、故事）
3. 记录**代表性原话**作为风格锚点
4. 分析**演讲结构**（开头模式、论证方式、结尾风格）
5. 交叉对比不同时期、不同渠道的**一致性**

### 6个维度的分析过程

#### 维度1：核心性格画像

**分析方法**: 看他反复强调什么价值观，怎么描述理想人格，怎么处理选择。

**关键发现**:

| 性格特征 | 证据 | 来源 |
|---------|------|------|
| 从容 | 提出「慢科学」概念——「不是慢慢地做科学，而是一种从容的科研态度」 | 2025开学典礼 |
| 内省 | 多次引用「君子慎独」，强调内在约束 | 贯穿多篇演讲 |
| 温润 | 课题组取名「春风希语」，讲话从不居高临下 | 课题组网站+所有演讲 |
| 坚韧 | 2003年主动离开吉大去清华「二次创业」 | 2014清华毕业演讲 |
| 谦逊 | 引用海明威「真正的高贵不是优于别人，而是优于过去的自己」 | 2022开学典礼 |
| 有为 | 「学习从来没有捷径，勤奋自律是关键」 | 2022开学典礼 |

**结论排序**: 从容 > 内省 > 温润 > 坚韧 > 谦逊 > 有为

**一句话画像**: 一个把「慎独」刻进骨子里的温润学者，在从容中见力量，在内省中求超越。

#### 维度2：思维模式

**分析方法**: 看他怎么组织观点、怎么论证、怎么把复杂问题讲清楚。

**关键发现**:

```
思维特征 #1: 框架构建型
  证据: 「信息≠知识≠智慧」三段论
  来源: 2022开学典礼

思维特征 #2: 归纳类比型
  证据: 导电高分子故事 → 论证「从失败中洞察机遇」
  来源: 2025开学典礼

思维特征 #3: 战略前瞻型
  证据: 「知道适时终止原方向、开拓新方向是一个成功学者的必备素质」
  来源: 中国科学报专访
```

**特别发现**: 他极度喜欢用**三段递进**结构：

| 递进结构 | 三段内容 |
|---------|---------|
| 认知层次 | 信息 → 知识 → 智慧 |
| 人生态度 | 内省 → 勇气 → 达观 |
| 教育理念 | 厚基础 → 重实践 → 严要求 |
| 教师情怀 | 师者情怀 → 学者情怀 → 家国情怀 |
| 科研境界 | 昨夜西风凋碧树 → 衣带渐宽终不悔 → 众里寻他千百度 |

#### 维度3：说话风格（最关键维度）

**分析方法**: 逐句阅读演讲全文，标记语气词、句式、修辞、节奏。

**四大风格锚点**:

```
锚点1: 引经据典但不掉书袋
  → 引用孔子「内省不疚，夫何忧何惧」后，会用现代语言解读
  → 引用王国维「三境界」后，映射到当代学生的科研阶段

锚点2: 故事驱动论证
  → 讲导电高分子的故事 → 论证「从失败中洞察机遇」
  → 讲DDT的故事 → 论证「科学需要伦理约束」
  → 讲年轻科学家的案例（穆斯堡尔29岁、沃森25岁）→ 鼓励年轻人

锚点3: 温和中暗含力量
  → 从不说「你应该」「你必须」
  → 常用「不妨……」「我的经验是……」「我们可以……」
  → 但在学术伦理上立场毫不含糊

锚点4: 金句收束
  → 每篇演讲结尾都有简练有力的结语
  → 「人比山高，脚比路长」「慎始敬终，不负韶华」
```

**代表性原话（12句金句）**:

```
1. "人比山高，脚比路长"
2. "凌峰顿觉天地宽"
3. "Science is People"
4. "真正的高贵不是优于别人，而是优于过去的自己"
5. "学习从来没有捷径，勤奋自律是关键"
6. "信息并不等于知识，知识也并不等于智慧"
7. "内省不疚，夫何忧何惧"
8. "从失败中洞察机遇"
9. "经得起时间考验的工作才是好成果"
10. "年轻人超越老师的最好办法是开拓新方向"
11. "勇气是压力之下的优雅"
12. "慢科学不是慢慢地做科学，而是一种从容的科研态度"
```

#### 维度4：知识结构与世界观

## 附录C：踩坑与经验总结

### C.1 搜索相关

| 问题 | 现象 | 原因 | 解决方案 |
|------|------|------|---------|
| 空JSON | 搜索返回 `[]` | 查询词太宽泛 | 添加上下文限定词，如「学术 观点」 |
| 内容过滤 | 错误1301 | 查询含「性格」「评价」等敏感词 | 改用中性词如「理念」「演讲」 |
| 中文效果差 | 英文搜索返回不相关结果 | 未指定 `location="cn"` | 中文人物必须用 `location="cn"` |
| 摘要太短 | 搜索结果只有1-2行 | 默认 `content_size="medium"` | 改用 `content_size="high"` |

### C.2 素材提取相关

| 问题 | 现象 | 原因 | 解决方案 |
|------|------|------|---------|
| URL失效 | web_extract返回错误 | 大学网站改版/文章下线 | 标记跳过，找替代来源 |
| 私有网络拦截 | 「Blocked: private network」 | 安全策略限制 | 搜索摘要可能已够用 |
| B站无转录 | 只获取到标题和标签 | B站无公开字幕API | 搜索对应的文字稿原文 |
| PDF提取失败 | PDF URL超时 | PDF文件过大 | 用浏览器工具或curl下载后本地读取 |

### C.3 合成策略相关

| 策略 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| 单次 delegate_task(orchestrator) | 一致性好、上下文完整 | token消耗大、可能超时 | 素材丰富、质量要求高 |
| 分步 delegate_task（7次） | 每步消耗少、灵活 | 一致性差、上下文断裂 | 素材少、只需部分文件 |
| 直接在主代理生成 | 最快、零额外消耗 | 主代理上下文压力大 | 素材很少、只需SOUL.md |

> **本案例的选择**: 单次 orchestrator，因为素材丰富（10篇全文）且要求全套9文件。如果超时，可以拆分为「分析+画像」和「生成文件」两步。

### C.4 风格设计相关

| 陷阱 | 描述 | 本案例的应对 |
|------|------|-------------|
| 安全化陷阱 | 为了不出错，把所有尖锐特征都磨平，导致人格文件变得平庸 | 保留「学术伦理上绝不妥协」「不用幽默」「不说空话」等鲜明特征 |
| 金句库滥用 | AI每句话都从金句库抽取，变成复读机 | 设置引用计数器（不超过3次），金句只在收束时使用 |
| 性格分裂 | 不同文件间性格不一致 | 定义9个核心词汇交叉引用 + 一致性校验步骤 |
| 万能人格 | 写出来的配置任何人都能套用 | 用张希独有的特征锚定：「慢科学」「春风希语」「三段递进」等 |
| 过度设计 | Agent/工具太多太复杂 | 6个Agent（不多不少）+ 6种工具（覆盖主要场景） |

### C.5 关键经验

1. **搜索词设计比工具选择更重要** — 同样的搜索工具，好的搜索词和差的搜索词效果天差地别
2. **一手素材的价值远超二手转述** — 1篇演讲全文 > 10篇新闻报道
3. **时间跨度很重要** — 2010年和2025年的演讲对比，能发现不变的核心和演变的表达
4. **金句库是风格锚点** — 不是让AI背诵这些话，而是让AI理解这种句式和语气
5. **禁忌和正面特征同等重要** — 「不说空话」比「说有内容的话」更容易执行
