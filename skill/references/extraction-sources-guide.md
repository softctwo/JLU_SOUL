## 各渠道详细分析指南

### 1. 著作/书籍/论文

**最佳提取**: 思维模式、知识结构

分析方法:
- **章节结构** → 论证逻辑是演绎还是归纳？
- **引用文献** → 知识源头和思想流派
- **写作节奏** → 长句还是短句？密集还是疏朗？
- **段落结构** → 先结论后论据还是逐步推演？
- **脚注/附录** → 思维严谨程度
- **自序/后记** → 个人价值观和写作动机

关键问题:
- 这个人写东西是"搭积木"(先基块后整体)还是"剥洋葱"(从外到内)？
- 引用偏好：大量引用他人 vs 极少引用(更自信/原创)？
- 数学公式和图表的使用频率？

### 2. 公开演讲/主题演讲

**最佳提取**: 说话风格、思维模式

分析方法:
- **开场方式** → 幽默开场？故事开场？数据开场？直接切入？
- **节奏变化** → 什么时候加速？什么时候停顿？
- **与观众互动** → 互动频率和方式
- **PPT/视觉风格** → 极简？数据密集？大量图片？
- **结尾方式** → 行动号召？总结？悬念？金句？
- **即兴 vs 照稿** → 即兴能力强不强？

关键问题:
- 面对突发状况(设备故障/观众打断)的反应？
- 演讲和著作的风格一致性如何？
- 用什么方式让复杂概念变简单？

### 3. 访谈/对话/播客

**最佳提取**: 说话风格、情感模式、思维模式

分析方法:
- **回答长度** → 啰嗦还是精炼？
- **打断行为** → 经常打断别人还是耐心听完？
- **对尖锐问题的反应** → 闪躲？正面回答？反问？生气？
- **笑声频率和方式** → 什么时候笑？大笑还是微笑？
- **犹豫和停顿** → 在什么话题上犹豫？
- **对采访者的态度** → 平等？居高临下？合作？

关键问题:
- 面对不友好的提问时，是变得更清晰还是开始模糊？
- 多次访谈中，核心观点是否一致？
- 描述他人时用词倾向(正面/负面/中性)？

### 4. 社交媒体/博客/公众号

**最佳提取**: 情感模式、日常行为习惯

分析方法:
- **发帖频率和时间** → 什么时候活跃？规律还是随机？
- **转发 vs 原创** → 比例和偏好
- **争论风格** → 在线争论时怎么表达？
- **情绪波动** → 不同日期/事件的情感变化
- **关注话题** → 持续关注什么？偶尔关注什么？
- **自我表露程度** → 分享私生活的意愿

关键问题:
- 线上风格和线下/正式场合风格差异多大？
- 社交媒体上的"人设"是否自洽？
- 对粉丝/批评者的互动模式？

### 5. 新闻报道/媒体评价

**最佳提取**: 核心性格(他人视角)

分析方法:
- **高频形容词** → 记者常用的描述词
- **关键事件叙述** → 在危机/转折点的行为
- **关系网络** → 经常和谁一起出现？谁是盟友/对手？
- **媒体偏见调整** → 不同立场的媒体描述差异

注意: 新闻报道是二手信息，需要交叉验证。同一事件在不同媒体中的描述可能完全不同。

### 6. 他人评价/传记/回忆录

**最佳提取**: 核心性格、行为习惯(他人视角)

分析方法:
- **共同评价** → 多人提到同一个特征 = 高可信度
- **矛盾评价** → 有人说是A有人说是B = 可能因场景而异
- **轶事故事** → 比形容词更有价值，能提取行为模式
- **评价者的立场** → 好友 vs 对手的评价权重不同

关键问题:
- 多个独立来源是否指向相同的性格特征？
- 最亲密的人(家人/长期合作伙伴)怎么描述TA？
- 竞争对手/批评者的评价中是否有共识？

### 7. 调查问卷/性格测试

**最佳提取**: 核心性格(结构化数据)

如果目标人物公开过 MBTI、大五人格、Enneagram 等测试结果，这是最直接的数据。但要注意:
- 自我报告的偏差(可能选择了"理想自我"而非"真实自我")
- 不同测试结果可能矛盾
- 性格类型是简化模型，不能完全定义一个人
- 测试结果应作为参考维度之一，而非唯一依据

### 8. 日常工作输出

**最佳提取**: 思维模式、知识结构、行为习惯

对于程序员/设计师/创作者等职业人物，他们的工作产出是极好的分析素材:
- **代码风格** → 注释习惯、命名风格、架构偏好
- **设计作品** → 美学偏好、功能优先级
- **文档/邮件** → 正式程度、组织方式、关注重点
- **Git commit/PR** → 工作节奏、协作方式、对细节的执着程度

## 素材质量评估标准

搜集完素材后，按以下标准评估质量：

| 维度 | 高质量 | 中等 | 低质量 |
|------|--------|------|--------|
| 来源可信度 | 本人产出(著作/演讲) | 权威媒体采访 | 匿名爆料/小道消息 |
| 时效性 | 近3年内 | 3-10年 | 10年以上 |
| 一手性 | 本人直接表达 | 经过编辑/翻译 | 他人转述 |
| 数量 | 10+独立来源 | 5-10个 | <5个 |
| 多样性 | 覆盖3+渠道 | 2个渠道 | 单一渠道 |

素材质量直接决定最终人格文件的**置信度等级**。
