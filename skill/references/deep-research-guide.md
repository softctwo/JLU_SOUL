# 深度研究方法论 (Deep Research Guide)

> 用于路径B（真实人物提炼）的增强信息搜集与分析方法

---

## 为什么需要深度研究？

简单搜索只能获取人物的基本信息和片段引用。要准确提炼一个真实人物的人格，需要：

1. **足够的素材量** — 至少 5000+ 字的一手资料
2. **多维度覆盖** — 演讲、访谈、论文、社交互动、他人评价
3. **时序深度** — 不同时期的表达风格可能有变化
4. **非文字信息** — 视频、音频中的肢体语言、语气、节奏
5. **交叉验证** — 单一来源不可靠，需多方印证

## 深度研究流程 (5阶段)

### 阶段1：基础画像 (5-10分钟)

**目标**：建立人物的基本事实框架

**操作**：
```
1. 用 mcp_web_search_prime 搜索 "[人物名] 简介 生平 成就"
2. 用 mcp_web_search_prime 搜索 "[人物名] 维基百科 / 百度百科"
3. 用 web_extract 提取维基/百科全文
4. 整理为：基本信息卡 + 职业时间线 + 核心成就列表
```

**输出格式**：
```markdown
## 基本信息卡
- 姓名：
- 出生：
- 职业：
- 教育背景：
- 主要成就：
- 所在机构：

## 职业时间线
[年份] - [事件]
[年份] - [事件]
...

## 核心成就 Top5
1. ...
2. ...
```

### 阶段2：深度素材搜集 (15-30分钟)

**目标**：从多渠道获取丰富的一手素材

**2.1 演讲/致辞搜索**（P0优先级）
```
搜索词设计：
- "[人物名] 演讲 原文"
- "[人物名] 致辞 全文"
- "[人物名] 访谈 对话"
- "[人物名] 毕业典礼/开学典礼/颁奖典礼"  # 学者型
- "[人物名] 发布会/访谈/对话"              # 企业家型
- "[人物名] lecture speech interview"       # 英文素材

使用工具：
- mcp_web_search_prime → 获取搜索结果
- web_extract → 提取全文（一次最多5个URL）
- mcp_zread → 深度阅读长文（对重要演讲做深度解析）

关键操作：
- 每次搜索后，挑选最相关的 2-3 篇全文提取
- 优先选择包含完整原文的页面（转载 > 摘要）
- 特别关注"标题"中有人物名字的——往往是演讲原文
```

**2.2 视频素材搜集**（P0优先级）
```
搜索词设计：
- "[人物名] 演讲 视频"
- "[人物名] 采访 视频"
- "[人物名] site:bilibili.com OR site:youtube.com"
- "[人物名] 访谈 完整版"

处理方式：
A. YouTube视频 → 搜索 YouTube URL → 用 youtube-content 获取转录
B. B站视频 → 搜索 BV号 → 用浏览器访问获取简介和弹幕
C. 其他平台视频 → 搜索视频页面 → 截图分析关键帧
D. 新闻联播等 → 搜索新闻稿原文（视频的文字版更可靠）

视频分析重点：
- 非语言信息：语速、停顿、手势、表情
- 互动模式：如何回应提问、如何应对挑战
- 现场反应：即兴发挥 vs 照稿念
- 观众互动：是否脱稿、是否与学生合影等
```

**2.3 他人评价与公众形象**（P1优先级）
```
搜索词设计：
- "[人物名] 评价 怎么样"
- "[人物名] 学生/同事/朋友 评价"
- "[人物名] 争议"  # 了解全面性
- "如何评价[人物名] site:zhihu.com"

分析重点：
- 多方评价是否一致？
- 公众形象与学术形象的差异
- 关键争议事件中的表现
```

**2.4 著作/论文/专利**（P1优先级）
```
搜索词设计：
- "[人物名] 论文 代表作"
- "[人物名] 著作 书籍"
- "[人物名] Google Scholar"

分析重点：
- 研究方向的演变
- 写作风格（学术论文中的语言风格也有参考价值）
- 引用习惯
```

**2.5 社交媒体/公众号/博客**（P2优先级）
```
搜索词设计：
- "[人物名] 公众号 微博 博客"
- "[人物名] 个人主页 website"

分析重点：
- 日常表达风格（通常比正式演讲更随意）
- 关注话题和兴趣
- 互动模式
```

### 阶段3：深度内容分析 (10-20分钟)

**目标**：从素材中提炼具体的人格特征证据

**3.1 全文深度阅读**

对关键演讲/访谈全文，使用 `mcp_zread` 进行深度分析：

```
对每篇重要全文，提取：
- 核心论点和论证结构
- 引用典故/诗句/名人名言的清单
- 排比句、设问句等修辞手法统计
- 语气词和口头禅
- 开头和结尾的固定模式
- 情感表达的具体方式
```

**3.2 交叉对比分析**

```
将不同来源的信息进行交叉验证：
- 演讲中的价值观 vs 访谈中的价值观 → 是否一致？
- 公开场合的语气 vs 社交媒体的语气 → 有什么差异？
- 自己的描述 vs 他人的评价 → 有什么出入？
- 不同时期的表达风格 → 有什么演变？
```

**3.3 视频分析（如有视频素材）**

详见 `references/video-analysis-guide.md`

### 阶段4：人格维度定稿 (5-10分钟)

基于深度研究的结果，对6大分析维度进行最终定稿：

```
对每个维度：
1. 列出所有找到的证据（标注来源和可信度）
2. 去除只有单一来源且不可靠的证据
3. 综合可信证据得出结论
4. 标注置信度：高(多源交叉验证) / 中(2个以上来源) / 低(单一来源)
```

### 阶段5：质量评估与报告 (5分钟)

**信息质量评分**：

| 维度 | 评分标准 |
|------|----------|
| 素材丰富度 | A(10篇+全文) / B(5-10篇) / C(<5篇) |
| 一手资料占比 | A(>70%) / B(40-70%) / C(<40%) |
| 渠道多样性 | A(4+渠道) / B(2-3渠道) / C(单渠道) |
| 时序覆盖 | A(跨多个时期) / B(主要集中一个时期) / C(单一时间点) |
| 交叉验证 | A(多源一致) / B(部分交叉) / C(无交叉) |

**报告格式**：
```markdown
## 深度研究报告：[人物名]

### 研究概况
- 搜索次数：
- 全文提取数：
- 视频分析数：
- 总素材字数（估算）：

### 信息质量评分
| 维度 | 评分 |
|------|------|
| 素材丰富度 | |
| 一手资料占比 | |
| 渠道多样性 | |
| 时序覆盖 | |
| 交叉验证 | |

### 关键发现
1. ...
2. ...
3. ...

### 不确定项（需要更多信息）
1. ...
2. ...

### 素材清单
| # | 类型 | 标题 | 来源 | 字数 | 质量 |
|---|------|------|------|------|------|
| 1 | 演讲 | ... | ... | ... | 一手 |
| 2 | 访谈 | ... | ... | ... | 一手 |
| 3 | 报道 | ... | ... | ... | 二手 |
```

## 搜索结果处理最佳实践

### 1. URL优先级判断

从搜索结果中快速判断哪些URL值得提取全文：

```
优先提取：
✅ 人物所在机构官网的新闻稿（如 news.jlu.edu.cn）
✅ 权威媒体的专访/报道（如 people.com.cn, thepaper.cn）
✅ 演讲全文转载（如 news.eol.cn）
✅ 维基百科/百度百科
✅ 人物个人主页/课题组主页

不提取：
❌ 只有标题没有正文的聚合页
❌ 需要登录的页面
❌ 纯视频链接（无文字稿）
❌ 过于陈旧的信息（除非做历史对比）
```

### 2. 全文提取策略

```
web_extract 一次最多5个URL：
- 挑选最可能包含完整原文的5个
- 优先选择不同渠道的（避免重复）
- PDF URL直接传给 web_extract，会自动转markdown

mcp_zread 用于需要深度理解的超长文档：
- 重要的完整演讲（>3000字）
- 传记/回忆录章节
- 学术论文全文
```

### 3. 素材去重与整合

```
同一篇演讲可能被多个网站转载：
- 保留最完整的版本
- 标注原始出处和转载来源
- 如果不同版本有差异，以官网为准
```

## 与路径B工作流的集成

深度研究是路径B的增强版 B2 阶段：

```
原 B2 (简单搜索)：
  3次搜索 → 提取摘要 → 直接到B3分析

增强 B2 (深度研究)：
  阶段1(基础画像) → 阶段2(深度搜集) → 阶段3(深度分析) → 阶段4(定稿) → 阶段5(报告)
  
  然后 → B3(多维度人格分析，现在有丰富素材支撑)
```

建议在人物知名度为"中等"或"高"时自动启用深度研究。对于低知名度人物，可能搜集不到足够素材，仍用简单搜索。
